# ハムスターと行く中国旅行（仮）

ハムスターのナビゲーター「モチ」と上海を旅しながら、旅行で使う中国語を覚える Web アプリ。

## 起動方法

ビルド不要。`index.html` をブラウザ（**Chrome / Edge 推奨**）で開くだけで遊べます。

- 中国語の読み上げはブラウザ内蔵の音声（Web Speech API の speechSynthesis、zh-CN）を使います
  - NPC のセリフ・あなたの返事・会話の選択肢の横の 🔊 で何度でも聞けます
  - 読み上げの速さは **0.7x / 1.0x** から選べます（会話・覚える画面・設定のどこからでも切り替え可）
  - 端末に中国語音声が無い場合は、画面にお知らせを表示します
- 町の看板の中国語も読めます
  - 3D の空港・ホテルでは、看板を見ると「🔍 〜を読む」ボタンが出て、タップ（または E）でピンイン・意味・読み上げが出ます
  - 上海マップの「黄浦江」もタップすると読み上げと意味が出ます
- 「声に出して言ってみる」（音声認識）は Chrome / Edge で使えます。マイクの許可が必要です
- 進み具合はブラウザの localStorage に保存されます

## 遊び方の流れ

```
マップで今日のスポットを選ぶ
 → 🐹 案内（ハムスターが場面を説明）
 → 📝 覚える（中国語・ピンイン・音声・発音練習）
 → ❓ クイズ（日→中 / 中→日 / 聞き取り。間違えた問題は最後にもう一回）
 → 💬 本番（NPC との会話で実際に使う。正しく話すと旅が進む）
 → 🎉 結果（EXP・レベル・旅行達成率）
```

### 3D 空港（プロトタイプ）

上海マップの **✈️ 空港アイコン**（「3D」バッジ付き）をタップすると、3D の空港に入れます。
（マップ下の「空港へ行く」ボタンは、これまで通り 2D のレッスンです）

- 一人称視点で自由に歩ける。ハムスターがついてきて案内してくれる
- チェックインカウンターに近づくと「チェックインする」→ 你好 / 谢谢 を使う中国語イベント
- 空港にいる 8 人（座っている人・歩いている人など）に話しかけると、中国語で短い会話ができる（初回 +3 EXP）
- チェックイン後は探索モード。出発ボード・案内所・トイレ・搭乗口を見つけると豆知識
- 「← 上海マップへ戻る」でいつでも 2D マップへ

| 操作 | PC | スマホ |
|---|---|---|
| 歩く | W A S D / ↑ ↓（Space でダッシュ） | 画面左半分をドラッグ |
| 向き・視点 | ← → / マウスドラッグ | 画面右半分をドラッグ |
| 話す | E（または表示されるボタン） | 表示されるボタンをタップ |

### 3D ホテル

マップの **🏨 ホテルアイコン**から入れます（2D でホテルが解放済み、または 3D 空港をクリア済みなら OK）。

1. ロビー奥の **フロント（前台）** で王さんとチェックイン（我想办理入住・这是我的护照・好的、部屋番号「三零二」の聞き取り）
2. 左の **电梯（エレベーター）** で「三楼（3階）」を選ぶ
3. 3階の廊下で **302号室** を探してドアを開け、部屋に入るとクリア
4. ロビー・廊下の 6 人とも会話できる（ベルボーイ・ロビーのおばさん・ビジネス客・女の子・旅行者・スタッフ）

3D 表示には [Three.js](https://threejs.org/)（r128）を使い、3D 画面に入ったときだけ CDN から読み込みます（3D はインターネット接続が必要）。

### 学ぶ順番（上海）

| DAY | スポット | 内容 |
|---|---|---|
| 1 | ✈️ 空港 | あいさつ（你好 / 谢谢 / 再见） |
| 1 | 🏨 ホテル | チェックイン（我想办理入住 / 这是我的护照 / 好的） |
| 1 | 🥟 小籠包の屋台 | 数字 1〜5（聞き取り） |
| 2 | 🏪 コンビニ | 数字 6〜10・多少钱？ |
| 2 | 🍜 レストラン | 我要这个 / 好吃 / 买单 |
| 2 | 🚇 地下鉄 | 〜在哪里？ / 我要去〜 / 厕所在哪里？ |
| 3 | 🏙️ 外灘・🎤 ライブ・📺 ドラマ | 準備中 |

スポットは上から順に解放されます。クリア済みのスポットは何度でも遊べます（EXP は半分）。

### 続けやすくするしくみ

- 1スポット約5分。結果画面で「今日はここまででもOK」と伝える
- 連続日数は記録するだけで、途切れてもペナルティなし。久しぶりに開いても責めない
- 「復習」は覚えが弱い言葉から5問だけ

## 拡張のしかた

### 新しいスポットを追加する

1. `js/data/phrases.js` にフレーズを追加
2. `js/data/shanghai.js` の `spots` に追加（`comingSoon: true` を外すと遊べるようになる）
   - `intro` … ハムスターの案内
   - `scene` … 本番の会話。`say`（ユーザーが中国語で返す）と `understand`（NPC の言葉を聞き取る）を組み合わせる
   - 書式はファイル先頭のコメント参照

### 新しい 3D フィールドを追加する

1. `js/world3d/<場所>.js` にレイアウト（`build`）を書く（返す値は `engine.js` 冒頭のコメント参照）
2. `js/screens/<場所>3d.js` で `App.World3D.mount(root, cfg)` を呼ぶ（案内文・話す／調べる処理・クリア条件）
3. `js/data/shanghai.js` のスポットに `scene3d: '<場所>3d'` を書き、`index.html` に `<script>` を追加

### 新しい都市を追加する

`js/data/shanghai.js` をコピーして `App.CITIES.<id>` に登録し、`index.html` に `<script>` を追加。
