# ハムスターと行く中国旅行（仮）

ハムスターのナビゲーター「モチ」と一緒に、**2D で気軽に中国語を学び**、**覚えた言葉を 3D の北京で実際に使う**ゲーム。

## 起動方法

ビルド不要。`index.html` をブラウザ（**Chrome / Edge 推奨**）で開くだけで遊べます。

- 中国語の読み上げはブラウザ内蔵の音声（Web Speech API の speechSynthesis、zh-CN）を使います
  - NPC のセリフ・あなたの返事・会話の選択肢の横の 🔊 で何度でも聞けます
  - 読み上げの速さは **0.7x / 1.0x** から選べます（会話・覚える画面・設定のどこからでも切り替え可）
  - 端末に中国語音声が無い場合は、画面にお知らせを表示します
- 町の看板の中国語も読めます
  - 3D の空港・ホテルでは、看板を見ると「🔍 〜を読む」ボタンが出て、タップ（または E）でピンイン・意味・読み上げが出ます
  - 上海マップの「黄浦江」もタップすると読み上げと意味が出ます
- 「声に出して言ってみる」（音声認識）は Chrome / Edge で使えます。マイクの許可が必要です
- 進み具合はブラウザの localStorage に保存されます
- 3D 表示には [Three.js](https://threejs.org/)（r128）を使い、3D 画面に入ったときだけ CDN から読み込みます（3D はインターネット接続が必要）

## ゲームの流れ

```
📘 2D コースで中国語を学ぶ（1 レッスン約 5 分）
 → UNIT 1〜3：基本・あいさつ・自己紹介（初回はハムスターのチュートリアル）
 → UNIT 4「旅の準備」（空港・ホテルの言葉）をクリア
 → 🗺️ 北京旅行が解放！ スポットごとに「🌏 3D で歩く」か「💬 2D で会話する」を選ぶ
 → UNIT 5〜9 をクリアするたびに、行ける場所（屋台・料理店・名所・万里の長城）が増える
```

- **2D だけでも最後まで学べる**。3D は旅行気分を楽しみたい人が選べる
- 画面下のタブで **📘 学ぶ ⇄ 🗺️ 旅する** をいつでも切り替えられる
- 毎日やらなくても不利にならない（連続日数の表示なし・復習は「たまった分を少しずつ」）

| 5 | 数字・時間（1〜20・两・块・号・几点） | 🥟 小籠包の屋台 |
| 6 | 買い物（多少钱・太贵了・便宜一点・微信支付） | |

| 8 | 移動・交通（在哪里・一直走・左右・打车） | 🚇 地下鉄・🏛️ 天安門広場 |
| 9 | 旅行会話（门票・拍照・太美了・不到长城非好汉） | 🏯 故宮・🧱 万里の長城 |

### 問題の種類（`js/ui/exercise.js`）

- ✨ 新しい言葉のカード（中国語・ピンイン・🔊・🐢 ゆっくり）
- ❓ 4 択：日本語 → 中国語 ／ 中国語 → 意味 ／ 🔊 聞き取り
- 🧩 組み合わせ：言葉と意味をペアにする
- 🔤 並べ替え：日本語を見て、中国語の文を単語タイルで組み立てる
- 🎙️ 声に出す（音声認識・採点なし・スキップ可）
- 💡 文法ポイント（ハムスターの説明）

間違えた問題はレッスンの最後にもう一回出る。出題は**覚え度**（0〜5）に合わせて変わり（はじめて → カード＋やさしい問題、覚えてきた → 日→中・並べ替え）、
復習は**間隔反復**（覚え度が高いほど次の復習まで日をあける）で「時期が来た言葉・弱い言葉」から 10 問だけ出す。

## 🗺️ 北京旅行（3D・2D 会話）

| スポット | 3D | 内容 |
|---|---|---|
| ✈️ 空港 | ✅ | 北京首都国際空港を歩いてチェックイン。8 人と会話 |
| 🏨 ホテル | ✅ | フロントでチェックイン → エレベーターで 3 階 → 302 号室 |
| 🥟 小籠包・🍲 涮羊肉・🍜 炸酱面・🦆 北京ダック | ✅ | **王府井の屋台通り**（4 店すべて同じ 3D の通り）。小籠包は番号「三号」の呼び出しを聞き取る |
| 🚇 地下鉄・🏛️ 天安門広場・🏯 故宮 | 2D | 道をたずねる・チケットを買う・写真のマナー |
| 🧱 **万里の長城** | ✅ | 售票处で入場券（四十块）を買い、坂と階段を登って見張り台「好汉坡」へ。5 人と会話 |

3D の会話・イベントで出てくる言葉は、2D コースで覚えた言葉（`js/data/phrases.js` の id）を使っている。
お店や場所は対応するユニットをクリアしていないと 🔒 になり、ハムスターが「どのユニットで覚えられるか」を教えてくれる。

| 操作 | PC | スマホ |
|---|---|---|
| 歩く | W A S D / ↑ ↓（Space でダッシュ） | 画面左半分をドラッグ |
| 向き・視点 | ← → / マウスドラッグ | 画面右半分をドラッグ |
| 話す | E（または表示されるボタン） | 表示されるボタンをタップ |

## 拡張のしかた

### レッスン・言葉を追加する

1. `js/data/phrases.js` に言葉を追加（文なら `w: '我|wǒ 是|shì …'` を付けると並べ替え問題になる）
2. `js/data/course.js` のユニットの `lessons` に `{ id, title, ids: [...], notes?: [...] }` を追加

### 新しい都市を追加する

`js/data/beijing.js` をコピーして `App.CITIES.<id>` に登録し、`index.html` に `<script>` を追加。
スポットの `requires` に、行けるようになるユニットの id を書く。今の都市は `App.currentCityId` で切り替える。

### 新しい 3D フィールドを追加する

1. `js/world3d/<場所>.js` にレイアウト（`build`）を書く（返す値は `engine.js` 冒頭のコメント参照。坂は `heightAt`）
2. `js/screens/<場所>3d.js` で `App.World3D.mount(root, cfg)` を呼ぶ（案内文・話す／調べる処理・クリア条件）
3. 都市データのスポットに `scene3d: '<場所>3d'` を書き、`index.html` に `<script>` を追加
4. クリアしたら `App.Progress.markSpotCleared(spotId)` でマップに反映

## AI について（将来の拡張）

今はローカル AI・外部 API どちらも**使っていない**（決まった会話と問題だけで全機能が動く）。
「AI と自由に中国語で会話」「自由入力への返答」「添削」「習熟度に合わせた会話」を足すときは、
`js/core/ai.js` に provider を登録すれば画面側から呼べるようにしてある。

| | ローカル AI（ブラウザ内 / PC 上で動く小さなモデル） | 外部 API（クラウドの大きなモデル） |
|---|---|---|
| 会話・添削の質 | 小さいモデルだと中国語の自然さ・添削の正確さが落ちやすい | 高い。声調・語順・言い回しまで説明できる |
| 費用 | 無料（端末の性能しだい） | 使った分だけ料金がかかる |
| 動作環境 | 数百 MB〜数 GB のダウンロード。スマホや古い PC では重い | どの端末でも軽い（ネット接続が必要） |
| プライバシー | 入力が端末の外に出ない | 入力がサーバーに送られる |
| 必要なもの | モデルの配布・読み込みの仕組み | **API キーを置くサーバー（プロキシ）** |

**おすすめ**：まずは外部 API を**自分のサーバー経由**で使う形（質が高く、スマホでも動く）。
練習回数に上限を付けて費用を抑え、オフラインでも遊べるよう今の決まった会話はそのまま残す。

> ⚠️ API キーは**絶対にフロントエンド（このリポジトリの JS）に書かない**。ブラウザで動く JS は誰でも中身を見られる。
> キーはサーバーの環境変数に置き、ブラウザ → 自分のサーバー → AI API の順に中継する。
