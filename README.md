# ハムコシと征く中国旅行

ハムスターのナビゲーター「モチ」と一緒に、**2D で普通に中国語を学び**、**3D で中国を旅して冒険する**ゲーム。
勉強を強制せず、遊んでいるうちに中国語が身につくことを目指しています。

## 起動方法

ビルド不要。`index.html` をブラウザ（**Chrome / Edge 推奨**）で開くだけで遊べます。

- 中国語の読み上げはブラウザ内蔵の音声（Web Speech API）。速さは 0.7x / 1.0x で切り替え
- ハムスター（モチ）の案内は、録音した 50 音をつなげた声でしゃべります。吹き出しのオレンジの 🔊 で何度でも聞けます（設定の「モチの声」でオン・オフ）
  - 声は `tools/build_mochi_voice.py`、漢字の読みは `tools/build_kana_dict.py` で作ります（セリフを増やしたら読みの辞書を作り直す）
- タイトル画面の「🔊 タイトルコール」で、録音したタイトルコールが流れます（`tools/build_title_call.py` で作成）
- 「声に出して言ってみる」（音声認識）は Chrome / Edge で使えます。マイクの許可が必要です
- 進み具合はブラウザの localStorage に保存されます
- 3D 表示には [Three.js](https://threejs.org/)（r128）を使い、3D 画面に入ったときだけ CDN から読み込みます（3D はインターネット接続が必要）

## 2 つのモード（独立）

| | 📘 2D：中国語を学ぶ | 🗺️ 3D：中国を旅する |
|---|---|---|
| 内容 | Duolingo のような学習ゲーム（1 回約 5 分） | 街や観光地を歩き、人と話し、食事・観光・武術大会 |
| 進み方 | カテゴリの中を順番に | 3D の中でクリアした順に行き先が開く |
| 保存 | `state.course`・`learned`・`stats` | `state.trip`・`world3d` |

- **最初からどちらでも遊べる**。2D の進み具合は 3D の解放条件にしない（逆も同じ）
- 画面下のタブで **📘 学ぶ ⇄ 🗺️ 旅する** をいつでも切り替えられる
- 毎日やらなくても不利にならない（連続日数なし・復習は「時期が来た言葉を少しずつ」）

## 📘 2D 学習モード

`js/data/course.js`：4 カテゴリ・102 レッスン（各ユニットの最後に「まとめ」）。フレーズは 255 語（`js/data/phrases.js`）。

| カテゴリ | ユニット |
|---|---|
| 🔤 基礎 | 中国語の基本（ピンイン・声調・発音のコツ・基本の単語）／数字・時間・日付 |
| 📚 単語 | 食べ物・動物・人と家族・学校・仕事・趣味と武術・日常生活・場所と交通 |
| 🧩 文法と文章 | 語順（主語＋動詞＋目的語）・疑問文・否定文（不／没）・形容詞・時制とアスペクト（了／过／在／要）・読解 |
| 💬 会話 | あいさつ・自己紹介・友だちとの会話・買い物・食事・道案内と交通・旅行・観光・電話とメッセージ |

**問題の種類**（`js/ui/exercise.js`）：新しい言葉のカード／4 択（日→中・中→日・聞き取り）／組み合わせ／並べ替え／
**穴埋め**／**ピンイン入力**（声調記号なしで OK）／**読解**（短い文章 → 日本語で答える）／声に出す／文法ポイント／
**会話ロールプレイ**（チャット形式。以前のスポットごとの 2D 会話をここに移した）

- 間違えた問題はレッスンの最後にもう一回。出題は**覚え度**（0〜5）で変わる
- 復習は**間隔反復**。「📔 記録」で答えた数・正解率・14 日のグラフ・苦手な言葉が見られる

## 🗺️ 3D 旅行モード

マップ（`js/screens/map.js`）は**明るい絵地図（草原・川・池・木）の上に名所のイラスト**（`js/ui/landmarks.js`・オリジナル）が並ぶステージ選択画面。
「第一章 北京の旅」は上から番号順に進む曲がり道＋寄り道、「特別章 嵩山・少林寺」は高速鉄道で行く別の章。
名所は道路でつながり、通った道は黄色に（少林寺へは線路）。いまの行き先には「いまここ！」の札とモチ、クリアした場所には ★（★1 クリア・★2 その場所の半分の人と話した・★3 全員と話した）。
名所をタップすると概要と「出発する」が出る。

| | 行き先 | 内容 |
|---|---|---|
| 1 | ✈️ 空港 | チェックイン。8 人と会話 |
| 2 | 🏨 ホテル | フロント → エレベーター → 302 号室 |
| ↪ | 🏘️ 胡同さんぽ（寄り道） | 古い路地。鳥の散歩・毽子・三輪車・四合院のおばあちゃんなど 8 人。3 人と話すとクリア |
| 3 | 🏮 北京の商店街 | 北京ダック・涮羊肉・炸酱面・小籠包。**メニューを見て選ぶ → 注文 → 値段 → 会計**。お土産屋で値切り。街の人 11 人 |
| 4 | 🏛️ 天安門広場 | 案内人さんと記念写真 → 天安門の扉が開く |
| 5 | 🏯 故宮 | 售票处で入場券 → 检票口 → 太和殿でガイドさんの説明（4 と同じつながったフィールド） |
| 6 | 🧱 万里の長城 | 入場券を買って、坂と階段を登って好汉坡へ |
| ★ | 🥋 少林寺（河南省・高難度） | 空港に着いたらいつでも行ける特別な旅先。武術大会で 2 人の達人と連戦 |

**出発前の単語チェック**：次の場所で役立つ言葉を 2〜5 問。「挑戦する」「スキップして出発」「次から出さない」を選べて、
どれを選んでも不利にならない（設定でオン／オフ）。

**武術大会**（`js/ui/battle.js`）：オリジナルのボス 2 人。
- **林小飞**（疾風の少林拳士）… 速くて華麗。必殺技「**流星連華**」
- **沈岳**（孤高の武術家）… 冷静で誇り高い。必殺技「**十重封陣**」

登場演出・専用 BGM（WebAudio で生成）・HP ゲージ・必殺技演出・勝利報酬。中国語の掛け声（跳・蹲・左・右）でよけて、
師父の声（拳・腿・掌）で反撃する。負けても何度でも挑戦でき、「ヒント」で日本語も表示できる。練功場の木人桩で練習試合も。

| 操作 | PC | スマホ |
|---|---|---|
| 歩く | W A S D / ↑ ↓（Space でダッシュ） | 画面左半分をドラッグ |
| 向き・視点 | ← → / マウスドラッグ | 画面右半分をドラッグ |
| 話す・調べる | E（または表示されるボタン） | 表示されるボタンをタップ |

看板の中国語は近づくと「読む」ボタンで読み上げ・ピンイン・意味が見られる（`js/data/signs.js`）。

## 🛠 開発者向けテスト機能

URL に **`?dev=1`** を付けて開く（`?dev=0` で終了）。タイトル上の小さなラベル（「中国語で旅するゲーム」）を 7 回タップでも切り替え。

- **テスト用セーブ**（別の保存場所）を使うので、ふつうのセーブデータは壊れない（入ったときにコピーされる）
- 画面左下の 🛠：全レッスン解放・全ステージ解放・2D／3D を全部クリア扱い・テスト用セーブのリセット
- 「⏭ スキップ（開発）」ボタン：レッスン・3D の会話イベント・ボス戦
- ふつうのプレイヤーにも：チュートリアル（説明）のスキップ、単語チェックのスキップ

## 拡張のしかた

- **レッスン・言葉**：`phrases.js` に言葉（文なら `w: '我|wǒ 是|shì …'` で並べ替え・穴埋めに出る）→ `data/course.js` にレッスン
- **3D の行き先**：`world3d/<場所>.js`（レイアウト・人）＋ `screens/<場所>3d.js`（イベント・クリア条件で `App.Trip.clear(id)`）
  → `data/trip.js` にステージ（`after` で開く順番、`words` で単語チェック）→ `index.html` に `<script>`
- **会話**：`{ type: 'line' | 'understand' | 'say' | 'hamster' | 'menu' }`。`menu` で選んだ料理は後のセリフの `{zh}` `{price}` などに入る
- **新しい都市**：`data/trip.js` に地域とステージを足す（地域ごとにマップのパネルが分かれる）

## AI について（将来の拡張）

今はローカル AI・外部 API どちらも**使っていない**（決まった会話と問題だけで全機能が動く）。
`js/core/ai.js` に provider を登録すれば、自由会話・添削・習熟度に合わせた会話を画面側から呼べる。

| | ローカル AI | 外部 API |
|---|---|---|
| 会話・添削の質 | 小さいモデルだと落ちやすい | 高い |
| 費用 | 無料（端末の性能しだい） | 使った分だけ |
| 動作環境 | 数百 MB〜数 GB。スマホでは重い | どの端末でも軽い（ネット必須） |
| プライバシー | 端末の外に出ない | サーバーに送られる |
| 必要なもの | モデルの配布の仕組み | **API キーを置く自分のサーバー（プロキシ）** |

**おすすめ**：外部 API を自分のサーバー経由で使い、今の決まった会話はオフライン用に残す。
> ⚠️ API キーは**フロントエンド（このリポジトリの JS）に書かない**。サーバーの環境変数に置いて中継する。
